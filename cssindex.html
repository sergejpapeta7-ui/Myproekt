CSS (Cascading Style Sheets — «каскадные таблицы стилей») — это язык, который отвечает за внешний вид веб-страниц: цвета, шрифты, отступы, расположение блоков и многое другое. Я подобрала для вас самое важное: что это за язык, как он устроен, зачем нужен и какие есть нюансы.

Немного истории

Концепцию CSS предложил Хокон Виум Ли в 1994 году, а первую спецификацию выпустил консорциум W3C в 1996-м. Со временем язык сильно развивался: появились модули (CSS2, затем CSS3), а в последние годы особенно активно развиваются инструменты для сложной вёрстки — Flexbox (для гибких строк) и Grid (для двумерных макетов). Что он делает

Главная идея CSS — разделить структуру контента и его визуальное оформление. HTML задаёт каркас (заголовки, абзацы, списки), а CSS описывает, как этот контент должен выглядеть. Это даёт несколько плюсов: Легко менять дизайн, не трогая структуру HTML. Можно повторно использовать стили на разных страницах. Улучшается доступность: CSS позволяет контролировать отображение текста, что полезно для пользователей с ограниченными возможностями. Проще создавать адаптивные дизайны: с медиа-запросами можно менять отображение под разные устройства.

Как это устроено

Основа CSS — правила. Каждое правило состоит из трёх частей: Селектор. Указывает, к каким HTML-элементам применять стили. Это может быть тег (p, h1), класс (.button), идентификатор (#header), универсальный селектор (*) или даже атрибут ([type="text"]). Свойство. Определяет, какую характеристику элемента вы хотите изменить (например, color — цвет текста, font-size — размер шрифта, background-color — цвет фона). Значение. Даёт конкретное значение для свойства (ключевое слово, HEX-код, число, длина и т.д.).

Ключевые принципы

Каскадность. Если к одному элементу применимо несколько правил, порядок их следования в коде имеет значение. При одинаковой специфичности приоритет у того правила, которое расположено ниже. Наследование. Некоторые свойства передаются от родительского элемента к дочерним. Например, если задать шрифт для , все текстовые элементы внутри него его унаследуют, если где-то не переопределены. Специфичность. Это механизм, который решает конфликты: у разных селекторов разный «вес», и правило с более высоким весом имеет приоритет.
